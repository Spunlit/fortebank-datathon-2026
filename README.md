# ForteBank Datathon 2026 — локальный видеоаудит

Прототип сервиса анализа видео на локальной Qwen3-VL-4B-Instruct (NF4).
FastAPI принимает MOV, возвращает идентификатор задачи, статус, вердикт,
описание и кадр с временной меткой. Внешние AI API для обработки видео не используются.

**Статус:** HTTP-инфраструктура проверена; качество текущего детектора
недостаточно для эксплуатации. Обучение весов не выполнялось.

## Запуск

Проверенное окружение: Windows, Python 3.13, NVIDIA RTX 5060 Laptop 8 ГБ,
PyTorch 2.7.1+cu128. Версии HTTP-зависимостей находятся в
`requirements-service.txt`, inference — в `submission/requirements-inference.txt`.
CUDA-вариант PyTorch устанавливается из официального индекса соответствующих wheels.
Чистая установка на другом компьютере не проверена.

До запуска разместите официальные веса Qwen3-VL-4B-Instruct в
`.cache/models/Qwen3-VL-4B-Instruct`. Runtime загружает их только локально.
В уже подготовленном окружении:

```powershell
.\.venv\Scripts\python.exe scripts/start_local_api.py
```

UI: `http://127.0.0.1:8000/`. Ключ создаётся в
`local_only/deployment/api_key.txt` и передаётся жюри приватно.
Публичный URL сервиса предоставляется отдельно; адрес репозитория его не заменяет.
Один процесс сервиса, один worker; не используйте несколько uvicorn workers.

## API

| Запрос | Назначение |
|---|---|
| `POST /api/v1/analyze` | Multipart `file` с MOV; ответ содержит `job_id` |
| `GET /api/v1/jobs/{job_id}` | `processing`, `done` или `failed` |
| `GET /api/v1/health` | Готовность worker и счётчики |

Все API-запросы требуют заголовок `X-API-Key`. При `done` ответ содержит
`verdict` и `violations`; событие — `type`, `description`, `timecode_sec`,
`evidence_frames`. Кадр содержит `timestamp_sec` и JPEG `image_base64`.
Сбой возвращает `failed`, без вымышленного вердикта.

Ограничения: 100 МиБ на запрос, 3 принятые/ожидающие задачи, общий deadline 290 с.
Ожидание GPU входит в deadline. Его соблюдение не гарантирует успешный результат.

## Проверка

```powershell
.\.venv\Scripts\python.exe scripts/check_service.py
.\.venv\Scripts\python.exe -m unittest discover -s astra6_control/tests
```

Синтетическая HTTP-проверка прошла и после распаковки пакета в отдельный каталог.
Один локальный запрос с настоящей моделью завершился за **87,936 с**;
проверены JSON-контракт и совпадение кадра-доказательства с исходным PTS.
Эта проверка не измеряет точность распознавания.
Полный локальный workspace прошёл 278 тестов; сюда включён только набор тестов API.
Режим `check_service.py --real` требует непубличные локальные материалы проверки.
