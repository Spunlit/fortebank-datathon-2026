# Локальный видеоаудит — ForteBank Datathon

Исследовательский прототип: локальный Qwen3-VL-4B NF4, сервис FastAPI с очередью
и редактор для проверки временных фрагментов человеком. Обучение весов не выполнялось.

## Запуск на подготовленном ноутбуке

```powershell
.\.venv\Scripts\python.exe scripts/start_local_api.py
```

Ключ создаётся один раз в `local_only/deployment/api_key.txt`. Откройте этот файл
локально и вставьте ключ в UI либо приватное поле формы для жюри. Не включайте
ключ в презентацию, репозиторий или чат. Логи сервера сохраняются локально.

UI: `http://127.0.0.1:8000/`. Это локальный адрес, не публичный URL для жюри.
Редактор для команды: `http://127.0.0.1:8801/`; он не является контрактным API.
Модель загружается при обработке запроса и использует общую блокировку GPU с
редактором. Перекрывающиеся запросы могут ждать; общий deadline остаётся 290с.

## Контракт

1. POST `/api/v1/analyze`, заголовок `X-API-Key`, multipart поле `file` с `.mov`.
   Ответ: `{"job_id":"..."}`.
2. GET `/api/v1/jobs/{job_id}` с тем же ключом: `processing`, `done` или `failed`.
3. У `done` есть `verdict` (`violation` / `no_violation`) и список `violations`.
   Событие содержит `type`, `description`, `timecode_sec`, `evidence_frames`.
   Кадр содержит `timestamp_sec` и `image_base64`.
4. `failed` сообщает ошибку без вымышленного вердикта.

100МиБ максимум; 3 принятые/ожидающие задачи; очередь сверх лимита получает429.
Ключ не встраивается в клиентскую страницу и не сохраняется в браузере.

## Фактические ограничения

Подключённый API-детектор — отклонённый по качеству baseline. Нельзя заявлять
готовность к банковской эксплуатации, высокую точность или гарантированное
завершение любого видео за300с. Dense runner, редактор и исправленные примеры
исследуются отдельно и пока не заменили API-детектор.

В одном отдельном сравнении использование примеров увеличило число полностью
совпавших событий с0до1из4, одновременно увеличив ошибки ссылок с2до8. Поэтому
автоматическая активация отклонена; пробный режим редактора включается вручную.
Нормативная применимость к конкретным событиям пока не подтверждена.

## Локальность и воспроизводимость

После наличия весов inference работает offline; внешние AI API не используются.
Нужны установленные зависимости из workspace и веса в
`.cache/models/Qwen3-VL-4B-Instruct`. Видео, изображения, человеческие описания,
модельные ответы и секреты не включаются в публичный пакет.
Лицензии и версии: `../LICENSES.md`, `../requirements-service.txt` и журналы среды.
Версии inference-зависимостей: `requirements-inference.txt`; проверенное окружение
Windows / Python 3.13, PyTorch CUDA 12.8. Этот список не включает веса модели.
Чистая установка на другом компьютере не проверена; перед проверкой жюри
рекомендуется использовать уже подготовленный ноутбук.

Проверка инфраструктуры: `.\.venv\Scripts\python.exe scripts/check_service.py`.
Результаты этого теста не являются оценкой качества распознавания.

`api_source.zip` содержит исходники API, его тесты и материалы выступления.
Исследовательский runner и редактор в этот архив не включены. Для проверки
качества исправленных примеров нужен полный локальный workspace.
Точный перечень текущих проверок — `VERIFICATION.md`.
