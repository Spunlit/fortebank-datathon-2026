# Доступ к сервису команды Unemployed

- Веб-интерфейс: https://unemployed-forte.tail8454e0.ts.net/
- API base URL: https://unemployed-forte.tail8454e0.ts.net
- Анализ: POST `/api/v1/analyze`, multipart `file`.
- Статус: GET `/api/v1/jobs/{job_id}`.
- Авторизация: заголовок `X-API-Key`; ключ передаётся только в приватном поле формы.

Сервис выполняет inference на ноутбуке команды. HTTPS Funnel передаёт трафик
к порту8000; модель не размещена на стороннем AI API. Для доступности ноутбук
и Tailscale должны оставаться включёнными с работающим интернетом.
Редакторы разметки и каталог данных не публикуются.

Документация транспорта: https://tailscale.com/docs/features/tailscale-funnel
TLS завершается на устройстве команды; relay не расшифровывает содержимое.

После создания адреса возможна задержка обновления DNS. Это не подтверждение
качества модели: текущие ограничения перечислены в README и VERIFICATION.
