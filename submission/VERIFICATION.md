## Что исправлено

Windows broken pipe при проверке очереди worker больше не обрывает задачу
управления сервером: сервис сохраняет полученные сообщения и перезапускает
worker. GPU арендуется через общую локальную блокировку; после обработки модель
выгружается. Повреждённое видео проверяется до загрузки модели. Реальная HTTP-
проверка экспортирует только технические агрегаты, без имени видео и вердикта.

## Ограничения

Точность API-детектора недостаточна; новый детектор не был продвинут в сервис.
Один запрос за 88 секунд не гарантирует успешную обработку любого видео за 300 с.
Ожидание GPU редактора входит в общий deadline сервиса. Перед проверкой жюри
нужно завершить запросы редактора и оставить GPU для API.

Исправления человека сохраняются локально, веса модели не переобучаются.
Проба с примерами дала смешанный результат и не разрешает заявлять улучшение
качества. Нормативная привязка событий не подтверждена.

Публичный URL, внешняя проверка, публикация кода и отправка формы пока
не выполнены. Их нельзя считать завершёнными на основании этого отчёта.
