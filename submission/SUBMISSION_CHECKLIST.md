# Пакет сдачи — рабочий список

## Обязательно проверить перед отправкой

- [ ] Публичный HTTPS URL интерфейса открывается с другого устройства/сети.
- [ ] По этому же адресу работает POST `/api/v1/analyze` с X-API-Key и `.mov`.
- [ ] GET `/api/v1/jobs/{job_id}` возвращает контрактный статус и ответ.
- [ ] API-ключ передаётся жюри приватно; его нет в архиве, презентации или Git.
- [ ] Ноутбук подключён к питанию; сон и закрытие крышки не остановят сервис.
- [ ] Известны требования к времени доступности сервиса; если не уточнены,
  команда обеспечивает доступность на период проверки и отслеживает ошибки.
- [ ] Репозиторий/архив с кодом доступен по условиям формы. Публикацию подтвердить
  отдельно; видео, веса, ключи, local_only и семантические результаты не включать.
- [ ] В форме заполнены сведения команды и обязательные поля.
- [ ] Указаны фактические ограничения качества и неподтверждённая нормативная часть.
- [ ] Решение отправлено через официальную форму до указанного организаторами срока.

Публичный адрес и отправка формы НЕ выполнены автоматически. Согласно условиям
работы пользователя внешняя публикация требует отдельного подтверждения.
Транспорт публичного доступа также должен сохранять утверждённую границу данных;
не загружать датасет на чужую платформу ради демо.

## Материалы

- `pitch.html` — семь локальных слайдов, без внешних зависимостей.
- `pitch.pdf` — экспорт слайдов, если печать завершена.
- `PITCH_SCRIPT.md` — сценарий 5 минут и ответы на вопросы.
- `README.md` — назначение пакета, API и ограничения.
- `VERIFICATION.md` — выполненные проверки и оставшиеся ограничения.
- `PUBLIC_ACCESS_PLAN.md` — подготовленный маршрут публикации, ещё не включённый.

## Текущие блокеры

1. Публичный HTTPS адрес отсутствует; локальный адрес не подходит для удалённой проверки.
2. API использует baseline, не прошедший проверку качества. Исправления в редакторе
   не означают улучшение этого детектора.
3. Нет подтверждённой нормативной привязки каждого обнаруженного события.
4. Ограничение времени реализовано как завершение/ошибка по deadline, а не гарантия
   успешного анализа любого видео за пять минут.

Презентация не заменяет обязательные UI/API и не снимает эти блокеры.
